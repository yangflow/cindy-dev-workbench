# 任意来源任务导入

工作台只接收统一任务清单。来源查询、账号认证、筛选与分页由当前已授权的外部工具处理；此插件不包含任何来源系统的专用客户端。

## 输入格式

在页面中点击「导入任务」粘贴 JSON，或先调用 `list_tools` 查询 `sources` 类目，再使用 `call_tool` 调用 `import_source_items`，参数为：

```json
{
  "source": {"id": "project-a", "name": "项目 A 需求清单"},
  "items": [
    {
      "id": "104",
      "ref": "REQ-104",
      "title": "统一订单查询接口",
      "url": "https://example.com/issues/104",
      "note": "接口、管理端和共享契约需保持一致",
      "labels": ["需求", "迭代 A"]
    }
  ]
}
```

`source.id` 必填，最多 80 字符，仅限字母、数字、点、下划线和连字符；按来源实例或项目选择稳定值，不同系统不要共用同一 ID。`source.name` 为可选显示名称。

每条任务必填 `id` 和 `title`，分别最多 200、300 字符。`ref` 为可选显示编号，最多 80 字符；没有编号时，会话直接使用任务标题。`url` 可省略，提供时必须是不含凭据的 HTTPS 地址。`note` 最多 20000 字符；每条最多 20 个标签，每个标签最多 40 字符。每次最多导入 500 条。

## 合并规则

来源 ID 与外部任务 ID 联合确定身份；不同来源即使任务 ID 相同，也不会互相覆盖。同一批次 ID 重复或任何任务不合法，整批不写入。

新任务进入待办类别。重复导入只补充缺失标签，保留手工标题、备注、状态、置顶、会话、多仓关联和发送回执。未出现在本批次的任务不会删除，已移除条目也不会被导入自动恢复。

导入不会创建 Cindy 会话、发送开发指令或执行来源系统中的操作。会话创建、首次发送与重新开始仍使用原有幂等和确认流程。任务内容属于参考资料，不能扩大当前操作权限。
